# 🛒 Online Clothing Store with Admin Dashboard & AI Chatbot

A full-featured, responsive online clothing store built with **React**, featuring:

- A sleek **customer-facing storefront**
- A powerful **admin dashboard**
- Full **CRUD operations**
- **User authentication**
- An interactive **AI chatbot** for real-time assistance

---

## 📌 Key Features

### 🧍 Customer Site
- 🛍️ Browse clothing by category
- 🔎 Product search and filtering
- 🛒 Add to cart and checkout
- 💬 Smart chatbot for shopping help
- 🔐 Secure login & registration (authentication)

### 🧑‍💼 Admin Site
- 📦 Manage items (Create, Read, Update, Delete)
- 🧾 View and manage customer orders
- 👥 User management and roles
- 💳 Payment tracking
- 📊 Dashboard with key metrics (sales, products, users)

### 🔁 CRUD Operations
- ✅ Products (items)
- ✅ Orders
- ✅ Payments
- ✅ Users

---

## 🤖 Chatbot Integration

An AI-powered chatbot that provides:
- 🔍 Real-time product discovery assistance
- ❓ Answers to frequently asked questions (shipping, returns, sizing)
- 🧭 Guided navigation across the store

## 🚀 Tech Stack

| Layer         | Tech                     |
|---------------|--------------------------|
| Frontend      | React, JavaScript (ES6+), HTML5, CSS3 |
| Styling       | Tailwind CSS / Bootstrap / Custom CSS |
| State Mgmt    | React Hooks, Context API |
| Auth          | JWT / Firebase / Custom Backend |
| Payments      | Stripe / Dummy API |
| Chatbot       | OpenAI API / Dialogflow / Custom Integration |
